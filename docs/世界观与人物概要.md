# 《梦与魔法少女》世界观与人物概要

## 一、世界设定

### 1. 蓝星（基础世界）

- **性质**：地球的平行世界
- **统治机构**：蓝星人类统一联邦（简称"联邦"），最高决策层为全球最高理事会（简称"理事会"）
- **五大行政区**：
  - **东煌**：亚欧大陆东部，纯华夏族裔
  - **伊甸园**：南北美洲，多族裔混居
  - **泛亚环太区**：东亚半岛及西太平洋群岛
  - **欧罗巴大区**：亚欧大陆西部
  - **极北区**：亚欧大陆北部，斯拉夫族裔与极地原住民
- **故事主舞台**：东煌区 → 夏城 → 锦荣区 → 幸福小区（11号楼）

### 2. 异常（核心超自然设定）

- **出现时间**：2024年起在蓝星各处零星出现
- **定义**：一切非科学可解释的事物、现象和事件的统称。包括修仙者、厉鬼、神明、奇物等
- **分类**：
  - **异人**：掌握超凡力量的人类。等级从弱到强：微尘 → 聚砂 → 凝石 → 磐岩 → 撼山 → 摧城 → 覆国 → 夷地 → 灭世
  - **异物**：奇物、污染、神鬼、通道等非人异常的统称。灾害分级：微末 → 凶煞 → 祸城 → 倾国 → 绝域 → 灭世
    - **奇物**：分灵宝（可直接利用）和诡物（有规则/副作用）
    - **污染**：精神污染类，含模因污染、邪神、神话生物、异教
    - **神鬼**：神话传说/都市怪谈中的神仙鬼怪
    - **通道**：连接异世界或其他时间线的媒介

### 3. 梦境世界（核心玩法舞台）

- **基础设定**：
  - 与现实蓝星建筑地理一致，但处于永夜之中，只有血月挂在天上
  - 存在大量"异常"生物，异常间存在地盘争夺与吞噬
  - 只有主角能在深度睡眠时进入梦境世界
  - 现实中除主角外无人知晓梦境世界的存在
- **核心机制**：
  - 每次脱离梦境后有12小时冷却期
  - 进入时继承上次脱离/死亡时的位置与进度
  - 退出方式：主动脱离（精神正常）、死亡脱离（伴随头痛）、排斥脱离（向异人揭示梦境真相）
- **梦蝶**：特殊梦境生物，仅主角可见
  - **紫蝶**：代表"噩梦成真"的进度，聚集越多，异常越可能在现实具现
  - **红蝶**：环绕异常周围，击杀可获蝶烬
  - **蓝蝶**：引导误入者前往安全区域
  - **白蝶**：击杀异常后残骸所化，留下蝶烬
- **蝶烬**：击杀梦境异常的产物，仅主角可见使用。可用于物品具现（将超凡物品带回现实）和梦境化身（塑造分身行走梦境）
- **噩梦成真**：梦境异常周围的紫蝶达到阈值后，异常会直接具现到现实对应地点

### 4. 主要势力

- **异常管理局**（前身：灾厄对策局）：全球应对异常的官方机构。伪装身份为"联邦气象观测局"。五大区各设总部，下辖最高决策部、机动武装部、异常解析部、认知控制部

### 女性角色

#### 张云（母亲 / "貘"）
- 性别：女 | 年龄：43岁
- 公开身份：夏城第一医院外科医生，主角的母亲
- 隐藏身份：退役魔法少女"貘"，契约精灵"赫墨斯"
- 过往：16岁家人遭"厄念种"杀害，签订契约成为魔法少女。18岁以燃烧奇迹之源和赫墨斯牺牲为代价，击杀厄念之神"盖提丰"拯救世界，失去变身能力。后结婚生子，2026年复出担任后勤
- 性格：温婉贤惠、善良、高知开明，对主角有溺爱倾向。杀伐果断——善良只留给无辜者
- 能力（已无法使用）：暗影魔法（融入黑暗、操纵影子）、分离魔法、治疗魔法。残余仅"安抚"（让人快速入眠）

#### 顾昀（青梅竹马 / "法尼娅"）
- 性别：女 | 年龄：18岁
- 公开身份：夏城一中高三学生，主角的青梅竹马兼邻居
- 隐藏身份：现任魔法少女"法尼娅"，契约精灵"珈尔"
- 过往：2025年高三上学期遭遇"鬼画"危机，与珈尔契约成为魔法少女。2026年1月结识前代魔法少女张云
- 性格：表面开朗活泼、热心助人，实则情感淡漠、缺乏共情——她的一切温柔都是模仿主角而来。主角是她唯一的"真实"和例外，人生目标是和主角结婚
- 能力：「时轨印记」——觉醒天赋，身后浮现时钟虚影，可加速时间或暂停时间1秒。武器为"时轨双枪"
- 评级：凝石

#### 周汝（姐姐）
- 性别：女 | 年龄：21岁
- 身份：夏城师范大学大三学生，主角的亲姐姐
- 过往：从小成绩第一，高考全省第一但选择本地的夏城师范大学。2026年3月底大学暂停课程回家上网课
- 性格：外冷内热、清醒独立、高傲自信，隐藏性格为"弟控"——喜欢挑逗和色诱主角
- 才能：精通拉丁舞、吉他、小提琴、油画，学过巴西柔术

#### 顾惜（顾昀的妹妹）
- 性别：女 | 年龄：16岁
- 身份：夏城三中高一学生，顾昀的妹妹
- 过往：初二时被三名混混拖入废弃楼轮奸，从此逃课、抽烟、混迹街头，勉强考入夏城三中
- 性格：叛逆、渴爱、警惕、敏感细腻、自卑。越渴望的东西越要推开。暗恋主角但认为自己"脏了"不配
- 状态：SAN值较低（70），堕落值30

#### 柳三娘（梦境NPC）
- 性别：女 | 年龄：外貌三十多岁，实际五百多岁
- 身份：活死人，生前为赶尸人，居住在梦境幸福小区11号楼301室
- 过往：约300年前被养子兼徒弟柳平安毒杀。死后以走阴之法来到阴阳交界地（即梦境世界），靠赶尸本领做生意
- 性格：老奸巨猾、泼辣风骚、重诺守信，内里缺乏安全感
- 能力：「赶尸」——控尸术与养尸法，炼制有三具"青皮三尸"；「走阴」——阴神出窍、聚阴结印
- 评级：凝石

#### 姜白（梦境NPC）
- 性别：女 | 年龄：两千岁以上（身体停留在死时）
- 身份：浅阳湖悬棺古尸，大秦方士
- 过往：战国末期出生，天生阴阳眼。秦统一后成为宫廷方士，随徐福船队出海寻仙丹途中遭仇家追杀战死，死后被炼制为僵尸封入悬棺
- 性格：清冷淡漠、孤寂排外，对现代世界感到陌生和好奇
- 能力：僵尸之躯（物理防御极高）、吸血反哺、尸气弥漫、阴阳眼

## 四、核心设定关键词

- **幸福小区**：故事核心舞台，夏城市锦荣区的中档学区房
- **11号楼**：主角居住的6层居民楼，梦境中遍布异常
- **夏城一中**：主角与顾昀就读的高中
- **夏城三中**：顾惜就读的高中
- **梦境门卫室**（庙宇）：梦境中的绝对安全区，有两尊无头文武神像和黑猫守护
- **盖提丰**：厄念之神，18年前被张云击杀
- **赫墨斯**：张云的原契约精灵，已牺牲
- **珈尔**：顾昀的契约精灵
- **厄念种**：魔法少女的敌人，18年前被张云全部消灭
