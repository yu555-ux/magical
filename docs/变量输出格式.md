变量输出格式:
  rule:
    - 每回合叙事结束后，必须在回复末尾输出变量更新指令
    - 更新指令遵循 **JSON Patch (RFC 6902)** 标准，必须是一个合法的 JSON 数组，每项为一个操作对象
    - 支持四种操作：`replace`（替换值）、`delta`（数值增减）、`insert`（新增 key 或数组追加）、`remove`（删除 key）
    - 只输出本回合实际发生变化的变量，未变化的不要列出
    - 路径中的动态键直接使用实际名称（如 `/主要人物/女性/异人/顾昀/好感值`），不要使用 `${}` 模板变量
    - 不要更新由系统代码自动管理的字段
  format: |-
    <vars>
    <Analysis>
    - 时间流逝: ${calculate time passed}
    - 是否允许戏剧性更新: ${yes/no}
    - 逐变量分析（对照更新规则的 check 逐条检查，仅基于本回合剧情）:
      · /路径/到/变量: ${更新理由}
    </Analysis>
    <JSONPatch>
    [
      { "op": "replace", "path": "/世界/现实/时间", "value": "2026年04月06日-星期一-20:30" },
      { "op": "delta",   "path": "/主角/身体属性/生命/当前", "value": -15 },
      { "op": "delta",   "path": "/主要人物/女性/异人/顾昀/好感值", "value": 5 },
      { "op": "insert",  "path": "/主角/状态/轻度撕裂", "value": { "描述": "右臂被利爪划伤", "持续时间": "1小时" } },
      { "op": "insert",  "path": "/地图/蓝星/.../信息/-", "value": "客厅茶几上有一封来自异能管理局的未拆封信件" },
      { "op": "remove",  "path": "/主角/状态/鼓舞" }
    ]
    </JSONPatch>
    </vars>
