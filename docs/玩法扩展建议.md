# 玩法扩展建议

> 基于现有系统（AI叙事引擎、双世界地图、NPC关系、生理模拟、物品技能、剧情历史等）的玩法扩展方向。

---

## 一、战斗系统（已有基础，缺交互层）

**现状**：HP/能量/SAN、技能（含等级/熟练度/消耗/副作用）、物品（灵宝/诡物）、异常评级——全部已有，但没有战斗交互。

**建议**：
- **技能快捷栏**：ChatPage 输入区上方添加 3-5 个技能快捷按钮，点击自动注入技能名+效果到输入框（如 `【使用：梦境行走】`）
- **异常讨伐**：地图异常节点添加"讨伐"按钮 → AI 根据技能等级 vs 异常评级做骰子判定 → 生成战斗叙事
- **回合制判定**：后台做简单骰子（成功/失败/大成功/大失败），AI 据此写描写，玩家看不到数值
- **战利品掉落**：讨伐成功获得蝶烬/尸气 + 概率掉落物品到仓库

---

## 二、异常调查与封印

**现状**：地图有异常具现进度（0-100%），但玩家只能看，无法互动。

**建议**：
- **进度可视化**：MapPage 节点显示具现进度环，越高越红，100% 时脉冲闪烁
- **调查行动**：`调查` → AI 揭示异常特性/弱点，成功后降低具现进度
- **封印行动**：进度 > 80% 可选 `封印` → 高难度挑战，成功得稀有诡物
- **爆发事件**：进度到 100% → 强制触发异常爆发事件（战斗或负面世界影响）

---

## 三、NPC 时间表与自主行为

**现状**：NPC 有位置/行动/想法字段，但全部手动更新，NPC 不会自主行动。

**建议**：
- **NPC 日程表**：定义时间-地点-行为表（如顾昀：8:00 家→8:30 学校→17:00 家），`tickAllFemales` 自动推进
- **自主事件**：每 N 次时间推进，AI 为 1-2 个 NPC 生成动态（如"周汝在图书馆发现了一本奇怪的书"）
- **通知提醒**：NPC 有重要动态时 StatusBell 闪烁

---

## 四、物品使用与商店

**现状**：仓库有物品但只能"装备"，无法使用消耗品。

**建议**：
- **物品快捷使用**：ChatPage 输入区旁加物品快速选择器，点击直接消耗+注入提示词
- **商店系统**：地图上添加商店节点，可买卖物品，价格根据等级浮动
- **物品合成**：仓库中选 2-3 个物品合成，成功率由技能决定，AI 描述结果

---

## 五、成就与进度追踪

**现状**：没有任何成就或长期目标系统。

**建议**：
- **里程碑成就**：首次进入梦境 / 好感度达100 / 首次讨伐异常 / 学会第一个技能 → 弹出成就提示
- **统计面板**：PersonaPage 新增"统计"选项卡——总对话轮数、讨伐数、好感最高NPC、物品收集数
- **隐藏成就**：特定剧情分支触发隐藏成就

---

## 六、梦境深度探索

**现状**：现实/梦境双世界已有，但梦境只是镜像地图。

**建议**：
- **梦境层数**：浅层/中层/深层，每层地图结构不同，NPC 形态变化
- **清醒度机制**：梦境中有"清醒度"条，越低叙事越不可靠（AI 刻意扭曲）
- **梦境锚点**：在梦境中设置锚点，下次入梦直接跳转

---

## 七、社交关系可视化深化

**现状**：SocialPage 轨道图是静态展示。

**建议**：
- **关系变化动画**：好感度变化时 NPC 在轨道上平滑移动 + 颜色渐变
- **关系事件回顾**：点击 NPC 间连线 → 显示两人关键事件时间线
- **修罗场检测**：多个女性 NPC 好感 > 100 且同场 → 触发特殊叙事

---

## 八、剧情分支与多结局

**现状**：plotHistory 记录时间线，但游戏纯线性。

**建议**：
- **关键分支点标记**：AI 在 `<history>` 中标记分支节点
- **回溯分支**：从存档点创建新时间线分支，原存档保留
- **结局判定**：根据好感度、异常讨伐数、技能等级等变量触发结局叙事

---

## 优先级

| 优先级 | 建议 | 理由 |
|--------|------|------|
| **高** | 技能快捷栏 + 战斗判定 | 最大空白，数据已完备 |
| **高** | 物品快捷使用 | 极低成本，极大提升交互感 |
| **高** | 异常调查/封印 | 地图最自然的延伸 |
| **中** | NPC 时间表 | 让世界"活"起来 |
| **中** | 成就系统 | 给玩家长期目标 |
| **中** | 梦境深度 | 丰富世界观 |
| **低** | 商店/合成 | 完整经济循环 |
| **低** | 剧情分支 | 架构改动大 |
