# 人物变量注入系统 · 完整方案

> 基于位置路径的前缀匹配，对 `主要人物` 中的 NPC 进行分级过滤，通过四个独立宏注入到 AI 提示词中。

---

## 一、总览

系统中存储了完整的 NPC 数据（`主要人物` 变量）。如果全部发给 AI，会严重消耗提示词预算。通过比较 NPC 与主角的当前位置路径，过滤出"在场/在附近"的角色，按距离分级发送。

数据按性别+类型分四组，每组一个独立宏：

| 宏 | 数据来源 |
|------|---------|
| `{{FEMALE_STRANGER}}` | 主要人物.女性.异人 |
| `{{FEMALE_NORMAL}}` | 主要人物.女性.普通人 |
| `{{MALE_STRANGER}}` | 主要人物.男性.异人 |
| `{{MALE_NORMAL}}` | 主要人物.男性.普通人 |

每个宏替换为该组过滤后的人物文本。若该组为空或全部被过滤，替换为空字符串。

---

## 二、层级判定

### 2.1 路径解析

主角和 NPC 的 `当前位置`（字符串）各调用 `resolvePath`，得到路径数组：

```
主角: [蓝星, 东煌区, 夏城, 锦荣区, 幸福小区, 11号楼, 601室]
顾昀: [蓝星, 东煌区, 夏城, 锦荣区, 幸福小区, 11号楼, 602室]
```

### 2.2 判定规则

`commonPrefix` = 两条路径从头连续匹配的段数。

| 层级 | 条件 | 含义 |
|------|------|------|
| **L0 同节点** | 路径长度相等 且 `commonPrefix === 路径长度` | 两人在同一地点 |
| **L1 同建筑** | `commonPrefix === max(lenP, lenQ) - 1` | 两人仅差最后一段 |
| **L2 其他** | 不满足 L0、L1 的全部情况 | 在更远处，或无法解析 |

#### L0 示例

```
主角: [蓝星,...,11号楼,601室]  len=7
张云: [蓝星,...,11号楼,601室]  len=7
common=7, max=7 → common === 7 === max → L0
```
张云在家客厅，主角也在家 → 面对面。

#### L1 示例（三种情况）

```
情况① 同深度不同节点：
  主角: [蓝星,...,11号楼,601室]  len=7
  顾昀: [蓝星,...,11号楼,602室]  len=7
  common=6, max=7 → 6 === 7-1=6 → L1

情况② 主角更深（主角在子节点，NPC在父节点）：
  主角: [蓝星,...,11号楼,601室]  len=7
  NPC:  [蓝星,...,11号楼]        len=6
  common=6, max=7 → 6 === 7-1=6 → L1

情况③ NPC更深：
  主角: [蓝星,...,11号楼]        len=6
  NPC:  [蓝星,...,11号楼,602室]   len=7
  common=6, max=7 → 6 === 7-1=6 → L1
```

#### L2 示例

```
主角: [蓝星,...,11号楼,601室]  len=7
NPC:  [蓝星,...,夏城一中]      len=5
common=4, max=7 → 4 ≠ 6, 4 ≠ 7 → L2

NPC 解析失败 → 直接 L2
```

## 三、分级发送字段

| 字段 | L0 同节点 | L1 同建筑 | L2 其他 |
|------|-----------|-----------|---------|
| 年龄 | ✓ | ✓ | ✓ |
| 身份 | ✓ | ✓ | ✓ |
| 评级 | ✓ | ✓ | — |
| 好感值（女）/ 友善值（男） | ✓ | ✓ | ✓ |
| 堕落值（女） | ✓ | ✓ | ✓ |
| 当前位置 | ✓ | ✓ | ✓ |
| 当前状态 | ✓ | ✓ | ✓ |
| 当前想法 | ✓ | — | — |
| 身体属性 | ✓ | ✓ | ✓ |
| 基础属性 | ✓ | — | — |
| 特殊属性 | ✓ | — | — |
| 着装（女） | ✓ | — | — |
| 身体开发（女） | ✓ | ✓ | — |
| 技能（异人） | ✓ | — | — |
| 奇物（异人，非空时） | ✓ | — | — |
| 社交圈 | ✓ | — | — |

### 所有层级不发

- **检索词** → 不发给 AI
- **梦境NPC 字段** → 内部标记，不暴露

### 所有层级处理

- **空奇物** → 如果灵宝/诡物/物品全为空，不发送奇物字段

## 四、梦境过滤

```
主角 isDream === false → 只发 梦境NPC !== true 的角色
主角 isDream === true  → 只发 梦境NPC === true 的角色
```

---

## 五、输出格式

每个宏替换为**该组过滤后的裸 NPC 数据**（类 YAML 缩进文本），不含标签和说明文字。用户在世界书中自行编写标签和提示词。

```
顾昀:
  年龄: 18
  身份: 夏城一中高三学生...
  评级: 凝石
  好感值: 180
  ...
```

若该组为空或全部被过滤，宏替换为空字符串。

### 宏对照表

| 宏 | 数据来源 | 内容 |
|------|---------|------|
| `{{FEMALE_STRANGER}}` | 主要人物.女性.异人 | 女性 · 异人（魔法少女等） |
| `{{FEMALE_NORMAL}}` | 主要人物.女性.普通人 | 女性 · 普通人 |
| `{{MALE_STRANGER}}` | 主要人物.男性.异人 | 男性 · 异人 |
| `{{MALE_NORMAL}}` | 主要人物.男性.普通人 | 男性 · 普通人 |

### 世界书中的用法示例

```
<主要人物_女性异人>
以下为重要的女性异人相关信息:
{{FEMALE_STRANGER}}
</主要人物_女性异人>
```

## 七、边界情况

| 情况 | 处理 |
|------|------|
| 该组数据为空 | 宏替换为空字符串 |
| 该组全部被过滤（梦境不匹配或 L2 远） | 宏替换为空字符串 |
| NPC 的 `当前位置` 无法解析（resolvePath 返回 null） | 归入 L2 |
| `主要人物` 变量不存在 | 四个宏均替换为空字符串 |
| 主角当前路径解析失败 | 所有 NPC 归入 L2 |
