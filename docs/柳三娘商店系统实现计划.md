# 柳三娘商店系统实现计划

## 背景

为游戏"梦·异常"添加柳三娘（梦境301室的赶尸人NPC）的商店玩法。玩家在梦境中身处301室、且柳三娘在店时，可用「尸气」购买商品。

---

## 一、商店入口设计

### 方案：聊天区条件浮层（Banner）

不放在 ChatHeader 工具按钮区。商店是**游戏世界内的交互**而非元工具，入口应融入叙事区域。

### 位置与触发

- **位置**：聊天消息区顶部，ChatHeader 下方
- **出现条件**：`位于梦境 === true` + 玩家当前位置含 `301室` + 柳三娘 `当前位置` 含 `301室` + `交易开放 === true`
- **消失**：条件不满足时立刻隐藏

### 视觉设计

一条窄横幅，高度约 52px，横向铺满消息区：

```
┌──────────────────────────────────────────────────────────┐
│  │                                                       │
│  │ 💀  柳三娘靠在八仙桌旁，旱烟的青雾在她指尖缠绕——      │
│  │     "来客人了？随便看看，不买别碰。"   [🛒 浏览商品]  │
│  │                                                       │
└──────────────────────────────────────────────────────────┘
```

**配色策略**：

整个横幅使用**暖金色调**，与系统主题的冷青蓝色形成区分。

| 元素 | 颜色 | 说明 |
|------|------|------|
| 背景 | `bg-amber-950/15` + `backdrop-blur-sm` | 暖暗半透明底 |
| 左边框 | `border-l-2 border-amber-500/40` | 金色细线视觉锚点 |
| NPC 台词 | `text-amber-200/70` | 柔和金色文字 |
| 浏览按钮 | `bg-amber-500/15 border border-amber-500/30` | 半透明琥珀按钮 |
| 按钮 hover | `bg-amber-500/25 border-amber-400/50` | 悬停更亮 |
| 按钮文字 | `text-amber-300` | — |

**按钮细节**：

- 圆角 pill 形状（`rounded-full`），与系统的方角按钮区别
- 轻微脉冲呼吸动画（`animate-glow-breathe`）
- 左侧 `ShoppingBag` 图标（12-14px）
- hover 时 scale(1.03) + 边框发亮，click 时 press-scale

**NPC 台词随机池**（每次 `visible` 从 false→true 时重新随机一条）：

> - "来客人了？随便看看，不买别碰。"
> - "哟，又来照顾三娘生意了？"
> - "货都在这儿了。尸气带够了没？"
> - "这些可都是三娘压箱底的好东西……"

**入场/退场动画**：

```
入场：height 0→52px, opacity 0→1, 从上方滑入（y: -8 → 0）
退场：height 52px→0, opacity 1→0, 向上滑出（y: 0 → -8）
时长：0.3s，ease: [0.22, 1, 0.36, 1]
```

## 二、首次相遇 —— 交易解锁机制

### 设计思路

玩家第一次到达 301 室时，柳三娘作为陌生人不会直接亮出商品。两人需要先见面、交谈、互相认识，柳三娘才会认可主角为顾客。这是叙事层面对"信任建立"的自然表达。

### 实现：`交易开放` 布尔标记

在变量树顶层新增 `特殊玩法` 节点，于其下存储交易解锁标记：

```
特殊玩法.柳三娘商店.交易开放: false
```

- **默认值**：`false`（新对话/首次到达时）
- **解锁时机**：AI 在两人第一次见面交谈的剧情中，通过 `<vars>` JSON Patch 将其设为 `true`
- **商店条件链**：`交易开放 === true` 作为 `checkShopAvailability` 的第四个条件

### 叙事流程示意

```
第一次到301室:
  玩家: "这里有人吗？"
  柳三娘: "……活人？居然有活人能走到这里。"
  [两人初次交谈、互相试探]
  AI 输出: <vars> [{ "op": "replace", "path": "/特殊玩法/柳三娘商店/交易开放", "value": true }] </vars>
  → 下次再进入301室时，banner 出现，商店可用

后续再到301室:
  banner 直接浮现 → 点击即可浏览商品
```

### 扩展可能

`交易开放` 只是第一道门。未来可以叠加更多条件：
- 好感值达到一定程度解锁隐藏商品
- 完成柳三娘的委托后上新
- 特定剧情后限时折扣

这些都可以用同样的模式在 `checkShopAvailability` 或 `getShopItems` 中叠加。

## 三、商品变量结构

### 存储位置

- **交易开关**：`特殊玩法.柳三娘商店.交易开放` — 解锁标记放在「特殊玩法」节点下，与角色档案分离
- **商品目录**：`柳三娘商店.商品` — 顶层独立变量，方便 AI 直接操作商品数据

两个变量分别建在 `default-world-vars.ts` 的末尾（`地图` 之后，`};` 之前）。

### 商品的世界观来源对照

| 商品 | 来源体系 | 柳三娘为何有此物 |
|------|----------|------------------|
| 镇尸符 | 传统神话（道教/赶尸） | 柳三娘自己的手艺，祖传符法 |

| 深海祭匕 | 克苏鲁神话 | 某个闯入梦境的异教徒遗落，柳三娘收容了它 |
| 纸人替身 | 民俗怪谈（扎纸匠） | 柳三娘闲时自己做的，用料粗糙但灵验 |

### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `分类` | `'灵宝' \| '诡物' \| '物品'` | 对应 `持有物品` 的三级分类 |
| `价格` | `number` | 单位：尸气 |
| `等级` | `string` | 微末 / 聚砂 / 凝石 / … 与物品等级体系统一 |
| `描述` | `string` | 商品描述文本，含风味叙事。购买后直接作为物品描述 |
| `效果` | `Record<string, string>` | 键值对，键为效果名、值为效果说明，购买后直接复制 |
| `库存` | `number` | 剩余可购数量，`0` = 售罄不显示。**不使用 -1 表示无限** |
| `规则` | `Record<string, string>`? | 仅诡物有此字段，使用规则/触发条件 |
| `副作用` | `string`? | 仅诡物有此字段 |

### 设计意图

- **字段与 `持有物品` 兼容**：购买时 `描述`/`效果`/`规则`/`副作用` 可直接复制，无需转换
- **库存为正整数**：简单直观，卖完即止。AI 未来可以通过 JSON Patch 补货
- **AI 可操作**：上新、调价、补货、下架均可通过变量修改完成
- **风味描述融入商品本身**：每件商品的描述都包含柳三娘的口吻和世界观来源，增强叙事沉浸感

### 默认值注入

在 `default-world-vars.ts` 地图节点之后新增 `特殊玩法` 和 `柳三娘商店` 两个顶层节点，包含上述 5 件商品、初始库存、以及 `交易开放: false`。

## 四、修改清单

### 1. 修改 `game/src/sillytavern/default-world-vars.ts`

在 `地图` 之后、顶层 `};` 之前，新增两个节点：

- `特殊玩法: { 柳三娘商店: { 交易开放: false } }`
- `柳三娘商店: { 商品: { ...5件商品及初始库存 } }`

### 2. 新建 `game/src/sillytavern/shop-engine.ts` — 购买引擎

导出函数：

**`checkShopAvailability(vars)`** — 返回 boolean，四个条件 AND：
1. `世界.梦境定位.位于梦境 === true`
2. 玩家位置含 `301室`
3. 柳三娘 `当前位置` 含 `301室`
4. **`特殊玩法.柳三娘商店.交易开放 === true`** ← 首次见面后 AI 解锁

**`getShopItems(vars)`** — 返回商品数组：
- 从 `柳三娘商店.商品` 读取
- 过滤 `库存 === 0` 的商品
- 转为数组格式

**`getPlayerCorpseQi(vars)`** — 返回 `主角.资源.超凡资源.尸气 ?? 0`

**`purchaseItem(itemName)`** — 异步函数，DB-first 模式：
1. 从 IndexedDB 读最新 chat
2. 校验商品存在、`库存 > 0`、尸气足够
3. 扣除尸气
4. `库存 -= 1`
5. 物品写入 `主角.持有物品[分类][名称]`（已存在则数量 +1）
6. 写回 DB，返回 `{ success, error? }`

### 3. 新建 `game/src/components/Pages/ChatPage/ShopBanner.tsx` — 商店入口浮层

**Props**：`visible: boolean`、`onOpenShop: () => void`

**内部逻辑**：
- 从 4 条台词池随机选取（`visible` false→true 时重新随机）
- `AnimatePresence` + `motion.div` 控制滑入/滑出动画
- 点击「浏览商品」→ `onOpenShop`

### 4. 新建 `game/src/components/Pages/ChatPage/ShopModal.tsx` — 商店弹窗

使用 `AetherModal` 包裹。内部自行从 DB 读取变量。

**结构**：
- 顶部栏：尸气余额 + "柳三娘的铺子"标题
- 分类过滤 pill：全部 / 灵宝 / 诡物 / 物品
- 商品卡片网格：名称、等级徽章、价格、库存数、简要描述
- 点击商品 → 详情面板：完整描述、效果、规则/副作用（诡物特有）、购买按钮
- 各状态处理

### 5. 修改 `game/src/components/Pages/ChatPage/index.tsx`

- 新增 state：`shopOpen`
- 新增 `useMemo`：`shopAvailable = checkShopAvailability(vars)`
- ChatHeader 下方渲染 `<ShopBanner visible={shopAvailable} onOpenShop={...} />`
- 新增 `<ShopModal>` 模态框

### 6. ChatHeader 不改动

## 五、关键设计决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 入口形式 | 消息区条件浮层 banner | 商店是游戏世界交互，不是元工具 |
| 入口配色 | 暖金色（amber），独立于系统冷青色 | 视觉上区分"柳三娘的地盘" |
| 首次解锁 | `交易开放` 布尔标记，AI 在首次交谈后设为 true | 叙事自然，信任建立过程 |
| 库存机制 | 正整数，卖完即售罄。不用 -1 | 简单直观，UI 直接显示数量 |
| 初始商品 | 5 件，覆盖传统神话/修仙/魔法/克苏鲁/民俗怪谈 | 展现世界观广度，后续可扩展 |
| 商品存储 | 游戏变量 `柳三娘.商店.商品` | AI 可动态调整 |
| 购买写入 | DB-first 异步模式 | 与 `moveItem` 一致 |

## 六、验证步骤

1. `npm run dev` 启动，新建对话
2. 默认状态 → 无 banner ✓
3. 设变量：`位于梦境=true`、位置含 `301室`、柳三娘位置含 `301室`，但 `交易开放=false` → **无 banner** ✓（首次见面未解锁）
4. 设 `交易开放=true` → banner 出现，台词随机，按钮有脉冲动画 ✓
5. 点击「浏览商品」→ 弹窗展示 5 件商品 + 尸气余额 + 库存数 ✓
6. 尸气不足 → 购买按钮 disabled ✓
7. 购买灵气丹（库存5）成功 → 尸气 -150、物品写入持有物品、灵气丹库存变为 4 ✓
8. 购买深海祭匕（库存1）→ 库存变为 0，下次打开商店不再显示 ✓
