# 子宫展示与过滤方案

## 一、数据流总览

```
default-world-vars.ts           character-filter.ts            AI Prompt
┌─────────────────┐           ┌─────────────────────┐        ┌──────────────┐
│ 子宫 (全量)       │──tick──→  │ filterUterusForAI() │──L0──→  │ 生理周期:     │
│  宫内精液: {...}  │           │                     │  L1    │   当前阶段    │
│  生理周期: {...}  │           │ 精简为 AI 可见字段    │  L2a   │ 宫内精液:     │
│  怀孕状态: {...}  │           └─────────────────────┘        │   总量,来源,   │
│  生育记录: [...]  │                                           │   注入时间     │
└─────────────────┘                                           │ 怀孕状态:     │
       │                                                       │   状态,父方,   │
       │ (全量读取)                                             │   受孕日期     │
       ▼                                                       └──────────────┘
┌─────────────────┐
│ ArchivePage     │  前端展示
│  当前阶段        │
│  精液量+来源     │
│  怀孕状态+父方   │
└─────────────────┘
```

## 二、三份数据——谁看什么

| 字段 | 前端显示 | AI 过滤文本 | 说明 |
|------|:---:|:---:|------|
| `生理周期.当前阶段` | ✅ | ✅ | "排卵期" / "安全期" / "经期" |
| `宫内精液.总量` | ✅ | ✅ | 整数 ml |
| `宫内精液.来源` | ✅ | ✅ | 注入者名字 |
| `宫内精液.注入时间` | — | ✅ | AI 需要推算精液存活天数 |
| `怀孕状态.状态` | ✅ | ✅ | 仅怀孕/产褥期时显示 |
| `怀孕状态.父方` | ✅ | ✅ | 仅怀孕/产褥期时显示 |
| `怀孕状态.受孕日期` | — | ✅ | AI 推算孕周 |
| `生理周期.上次经期日` | — | — | 代码内部用 |
| `生理周期.周期天数` | — | — | 代码内部用 |
| `生理周期.经期长度` | — | — | 代码内部用 |
| `生育记录` | — | — | 暂不展示，后续加 |

## 三、AI 过滤规则

### 3.1 与身体开发绑定

子宫与 `身体开发` 完全同显同隐：

```
L0 (同地点)     → 身体开发 + 子宫(精简版)
L1 (同建筑)     → 身体开发 + 子宫(精简版)
L2a (异地提及)  → 身体开发 + 子宫(精简版)     ← 继承 L1
L2b (未提及)    → 都没有
```

所有级别仅 `gender === 'female'` 时包含。

### 3.2 精简函数逻辑

`filterUterusForAI(uterus)` — 位于 `character-filter.ts`：

```
1. 生理周期.当前阶段              → 始终包含
2. 宫内精液.总量/来源/注入时间     → 仅当 总量 > 0 时包含
3. 怀孕状态.状态/父方/受孕日期     → 仅当 状态 !== '未孕' 时包含
```

### 3.3 AI 看到的文本示例（formatMap 渲染后）

未孕 + 排卵期 + 体内有精液：
```
子宫:
  生理周期:
    当前阶段: 排卵期
  宫内精液:
    总量: 5
    来源: {{user}}
    注入时间: 2026年04月25日-23:00
```

怀孕中：
```
子宫:
  生理周期:
    当前阶段: 排卵期
  怀孕状态:
    状态: 早孕
    父方: {{user}}
    受孕日期: 2026年04月25日
```

未孕 + 安全期 + 无精液：
```
子宫:
  生理周期:
    当前阶段: 安全期
```

### 3.4 实现位置

**`game/src/sillytavern/character-filter.ts`**：

- 新增 `filterUterusForAI(charData)` 函数
- `buildL0`（第 97-99 行 `身体开发` 之后）：添加 `子宫` 赋值
- `buildL1`（第 142-144 行 `身体开发` 之后）：添加 `子宫` 赋值
- `buildL2a`：继承 `buildL1`，无需改动
- `buildL2b`：无 `身体开发`，无需改动

## 四、前端展示规则

### 4.1 展示位置

`game/src/components/Pages/ArchivePage.tsx` — 在现有 `身体开发` 区块下方，新增同款粉色可折叠区块。

### 4.2 区块标题（动态摘要）

| 条件 | 标题文字 |
|------|---------|
| 未孕 + 安全期 | `子宫 · 安全期` |
| 未孕 + 经期 | `子宫 · 经期中` |
| 未孕 + 排卵期 | `子宫 · 排卵期` |
| 未孕 + 精液 > 0 | `子宫 · 排卵期 · 体内 x ml` |
| 怀孕 | `子宫 · 早孕（父: xxx）` |
| 产褥期 | `子宫 · 产后恢复中` |

### 4.3 展开内容

始终显示：
```
生理周期   当前阶段的值
```

有精液时（总量 > 0）：
```
宫内精液   总量 ml    来源: xxx
```

怀孕时（状态 !== '未孕'）：
```
怀孕状态   状态的值    父方: xxx
```

### 4.4 UI 风格

复用 `身体开发` 的粉色虚线边框风格（`border-pink-400/15` 等 class），默认折叠。
