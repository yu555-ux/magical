# 变量工具完整设计

> 对照：实际变量树 + 优化方案 B1 + 秋青传统酒馆规则
> 目标：LLM 不再需要 patch_state，所有变量操作都有专用工具

| 工具 | 覆盖 | 状态 |

## 覆盖缺口

### 🔴 P0 — 核心玩法必需

#### 1. 扩展 `update_resource`（修改已有工具）

当前支持：`生命/体力/能量/SAN/金钱/蝶烬/尸气`（主角）+ `生命/能量/SAN/好感/堕落/性欲/友善`（NPC）

**需新增的路径映射**：

| target | resource | 路径 | 类型 | range |
|--------|---------|------|------|-------|
| 主角 | 力量/体质/精神/敏捷 | `/主角/基础属性/{resource}` | number | 1-100 |
| 主角 | 幸运/魅力 | `/主角/特殊属性/{resource}` | number | 1-100 |
| 主角 | 评级 | `/主角/评级` | string | 枚举值 |
| NPC | 力量/体质/精神/敏捷 | `/主要人物/.../基础属性/{resource}` | number | 1-100 |
| NPC | 幸运/魅力 | `/主要人物/.../特殊属性/{resource}` | number | 1-100 |

改动量：在 `update_resource.execute` 的路径解析 switch 中加 5 个 case，约 15 行。

#### 2. `add_item` / `remove_item`（新工具）

管理主角和 NPC 的持有物品 + 仓库。优化方案 B1 原设计。

```
add_item({
  target: "主角" | NPC名,
  category: "灵宝" | "诡物" | "物品",
  itemName: "镇尸符",
  location: "持有物品" | "仓库",    // 存到哪里
  quantity: 1,                       // 数量
  properties: {                      // 完整物品条目
    等级: "微末",
    描述: "朱砂绘制的镇尸符箓",
    效果: { 镇尸: "对低级僵尸直接镇压" },
  },
  reason: "从柳三娘处购买",
})

remove_item({
  target: "主角" | NPC名,
  category: "灵宝" | "诡物" | "物品",
  itemName: "镇尸符",
  quantity: 1,                       // 减少数量，归零则删除条目
  moveTo: null | "仓库",            // null=彻底删除, "仓库"=移到仓库
  reason: "使用",
})
```

改动量：2 个工具定义 + 共享路径解析，约 80 行。

### 🟡 P1 — 常用操作

#### 3. `add_condition` / `remove_condition`（新工具）

管理主角和 NPC 的状态条目。之前已列入计划。

```
add_condition({
  target: "主角" | NPC名,
  name: "轻微擦伤",
  description: "左臂被碎片划伤，轻微疼痛",
  duration: "2小时",                // "永久" | "3小时" | "直到治疗为止"
  reason: "战斗中被飞溅的碎片划到",
})

remove_condition({
  target: "主角" | NPC名,
  name: "轻微擦伤",
  reason: "自然愈合",
})
```

变动量：2 个工具定义，约 50 行。

#### 4. `update_social`（新工具）

管理主角社交关系。遵循秋青规则"双向对称更新"。

```
update_social({
  target: NPC名,
  relationship: "朋友",             // 新关系（覆盖旧值）
  action: "set" | "remove",         // set=设置, remove=删除该社交条目
  reason: "一同经历了战斗",
})
```

变动量：1 个工具定义，约 40 行。

### 🔵 P2 — 辅助操作

#### 5. `update_outfit`（新工具）

管理 NPC 着装。秋青规则：更换衣物/战斗破损/亲密行为时更新。

```
update_outfit({
  target: NPC名,
  slot: "上衣" | "下衣" | "内衣" | "袜子" | "鞋子",
  name: "破损T恤",
  description: "战斗中撕裂的白色T恤，右肩处破了一个大口子",
  reason: "战斗中被敌人撕破",
})
```

变动量：1 个工具定义，约 35 行。

#### 6. `update_body_development`（新工具）

秋青规则：亲密行为时对应部位使用次数+1。

```
update_body_development({
  target: NPC名,
  part: "嘴巴" | "胸部" | "小穴" | "屁穴",
  increment: true,                   // true=使用次数+1, false=只更新描述
  description: null,                 // 可选：直接覆盖描述
  reason: "口交",
})
```

变动量：1 个工具定义，约 35 行。

#### 7. `update_npc_info`（新工具）

管理 NPC 跟踪信息（位置、行动、想法）。

```
update_npc_info({
  target: NPC名,
  field: "当前位置" | "当前行动" | "当前想法",
  value: "夏城一中·校门口",
  reason: "放学后在校门口等你",
})
```

变动量：1 个工具定义，约 35 行。
