# 生殖系统设计

> 纯规则驱动的生理模拟。代码负责全部计算，AI 只读取结果用于叙事。

---

## 一、变量结构

每个女性人物节点下新增 `子宫` 字段：

```
子宫: {
  宫内精液: {
    总量: 0.5,                    // number, 单位 ml
    来源: "周安",                  // string, 最近一次注入者
    注入时间: "2026年04月06日-20:00"   // string, 游戏时间，格式 "YYYY年MM月DD日-HH:MM"
  },
  生理周期: {
    上次经期日: "2026年03月28日",      // string, 格式 "YYYY年MM月DD日"，与世界日期对齐
    周期天数: 28,                  // number, 默认28
    经期长度: 5,                   // number, 默认5
    当前阶段: "排卵期"             // string, 代码写入，AI只读
  },
  怀孕状态: {
    状态: "未孕",                  // string, 代码写入
    受孕日期: null,                // string | null, 受精成功时写入，格式 "YYYY年MM月DD日"
    父方: null                     // string | null, 受精成功时从 宫内精液.来源 复制
  },
  生育记录: [                      // array, AI 写入，每次分娩追加一条
    // {
    //   生产日期: "2026年11月15日",  // string, 格式 "YYYY年MM月DD日"
    //   父方: "周安",                 // string
    //   孩子: "周小明"                 // string, 新生儿姓名/ID
    // }
  ]
}
```

**初始值**（未孕女性默认）：

```
宫内精液: { 总量: 0, 来源: null, 注入时间: null }
生理周期: { 上次经期日: "2026年03月28日", 周期天数: 28, 经期长度: 5, 当前阶段: "安全期" }
怀孕状态: { 状态: "未孕", 受孕日期: null, 父方: null }
生育记录: []
```

不同 NPC 的 `上次经期日` 和 `周期天数` 需要手动错开，避免所有角色同日排卵。

## 二、时间解析

### 2.1 世界时间格式

```
世界.现实.时间 = "2026年04月06日-星期一-20:00"
```

### 2.2 解析公式

从字符串中提取结构化数据：

```
正则: /(\d{4})年(\d{2})月(\d{2})日.*?(\d{2}):(\d{2})/

提取结果:
  year   = 2026
  month  = 4
  day    = 6
  hour   = 20
  minute = 0
```

### 2.3 计算两个日期之间的天数差

用 `new Date(year, month-1, day)` 可以正确处理跨月、跨年、闰年：

```
daysBetween(a, b) = floor( (new Date(b.year, b.month-1, b.day) -
                            new Date(a.year, a.month-1, a.day)) / 86400000 )
```

### 2.4 时间推进量

```
deltaHours = hoursBetween(上次tick时间, 当前世界时间)
```

小时差同样用 Date 差值除以 3600000。

### 2.5 tick 频率约定

**每游戏日执行一次 tick。** 日期系数即每日概率，无需再按 tick 拆分。

当世界日期跨越多日时（如玩家休眠跳过一段时间），tick 应补齐中间天数：逐日迭代，确保精液衰减、周期推进、受精判定的中间状态被正确处理。

## 三、生理周期

### 3.1 计算当前天数

```
daysSincePeriod = daysBetween(上次经期日, 世界日期)
currentDay      = (daysSincePeriod % 周期天数) + 1
```

`currentDay` 范围是 `1 ~ 周期天数`。

### 3.2 阶段判定

| 天数范围 | 阶段 |
|----------|------|
| 1 ~ 经期长度 | **经期** |
| (经期长度+1) ~ 13 | **安全期** |
| 14 ~ 16 | **排卵期** |
| 17 ~ 周期天数 | **安全期** |

天数边界用 `周期天数` 和 `经期长度` 动态计算，不硬编码：

```
if      currentDay <= 经期长度          → 经期
else if currentDay <  14               → 安全期
else if currentDay <= 16               → 排卵期
else                                    → 安全期
```

14 和 16 是"排卵期"的固定锚点，因为排卵通常发生在周期的中间（28天周期的第14-16天）。对于非常规周期（如 26 天），排卵窗口相对位置不变。

### 3.3 怀孕期间暂停

当 `怀孕状态.状态 != "未孕"` 时，**跳过周期计算**。怀孕期间黄体酮抑制排卵和月经，周期天数不再推进，`上次经期日` 冻结不动。

产后（`状态` 切回 `"未孕"` 时）重新设置 `上次经期日` 为当前世界日期，周期从零开始。哺乳期对周期恢复的延迟（现实可数月）暂时不建模，后续有需求可加。

### 3.4 经期首日自动更新

当世界日期跨过"上次经期日 + 周期天数"时，`上次经期日` 需要推进一个周期。这一步由代码检测并自动更新：

```
if daysSincePeriod >= 周期天数:
    上次经期日 = 上次经期日 + 周期天数
```

这样确保 `上次经期日` 始终是"最近一次经期开始日期"，`currentDay` 始终在有效范围内。

## 四、宫内精液

### 4.1 衰减模型

精液衰减率取决于所处生理阶段：

| 阶段 | 衰减率/小时 | 依据 |
|------|-----------|------|
| **排卵期** | **0.97** | 宫颈黏液稀薄呈碱性，精子可存活 3-5 天 |
| **非排卵期** | **0.85** | 宫颈黏液黏稠呈酸性，精子几小时内大量死亡 |

混合衰减公式（tick 逐日迭代时，按当天阶段逐段计算）：

```
// 伪代码：逐日衰减
for each day from 注入日 to 当前日:
    阶段 = 当天所处的生理阶段
    衰减率 = (阶段 == "排卵期") ? 0.97 : 0.85
    总量 = 总量 × 衰减率^24
```

排卵期衰减曲线（0.97/小时）：

| 时间 | 剩余比例 |
|------|---------|
| 0 小时 | 100% |
| 24 小时 | 48% |
| 48 小时 | 23% |
| 72 小时（3 天） | 11% |
| 120 小时（5 天） | 3% |

非排卵期衰减曲线（0.85/小时）：

| 时间 | 剩余比例 |
|------|---------|
| 0 小时 | 100% |
| 3 小时 | 61% |
| 6 小时 | 38% |
| 12 小时 | 14% |
| 24 小时 | 2%（基本清零） |

如果精液注入后跨越了阶段边界（如从排卵期进入黄体期），衰减率随之切换。逐日迭代而非单次公式，正是为了处理这种情况。

### 4.2 归零处理

```
if 总量 < 0.01:
    总量 = 0
    来源 = null
    注入时间 = null
```

### 4.3 AI 写入

性行为后，主 AI 通过 `<vars>` 写入。例如：

```xml
<vars>
主要人物:
  女性:
    普通人:
      周汝:
        子宫:
          宫内精液:
            总量: 5
            来源: "{{user}}"
            注入时间: "2026年04月06日-22:00"
</vars>
```

注入量（总量）由 AI 根据场景决定，一般范围 2-5ml。后续衰减全由代码处理。

## 五、怀孕状态机

### 5.1 状态流转

```
未孕 ──[受精判定通过]──▶ 受精 ──[孕2周]──▶ 早孕 ──[孕14周]──▶ 中孕 ──[孕28周]──▶ 晚孕 ──[孕38周]──▶ 产褥期 ──[产后6周]──▶ 未孕
```

妊娠全程 266 天（38 周），从受孕日起算。对比产科 40 周（280 天从末次月经起算），266 天是受精到分娩的真实时长。

### 5.2 概率模型

受孕概率由三层因素叠乘，与真实生理数据对齐：

```
单次 tick 受孕概率 = 日期系数 × 年龄系数 × 精液系数
```

#### 5.2.1 日期系数

真实受孕概率在排卵窗口内逐日不同——排卵前 1-2 天最高，排卵当天次之，排卵后骤降。排卵期覆盖周期第 14-16 天（共 3 天）：

| 周期天数 | 含义 | 日期系数 | 依据 |
|----------|------|---------|------|
| 第 14 天 | 排卵前日 | **0.12** | 排卵前 1-2 天受孕概率 25-30%/天 |
| 第 15 天 | 排卵日 | **0.09** | 排卵日本身约 10%/天 |
| 第 16 天 | 排卵后 | **0.05** | 卵子排出后 12-24 小时失活，概率骤降 |

三天累积：1 - (0.88 × 0.91 × 0.95) ≈ **24%**，吻合真实每周期受孕概率（~25%）。

#### 5.2.2 年龄系数

| 年龄段 | 系数 | 依据 |
|--------|------|------|
| < 20 | **1.1** | 青春期，生育力略高于巅峰 |
| 20-25 | **1.0** | 生育巅峰 |
| 25-30 | **0.9** | 缓慢下降 |
| 30-35 | **0.6** | 加速下降 |
| 35-40 | **0.3** | 真实每周期概率约 8-15% |
| ≥ 40 | **0.1** | 生育力极低，不再细分 |

#### 5.2.3 精液系数

6 个规范档位，档位之间线性插值，超过 50ml 用幂函数外推，不封顶：

| 精液量 | 系数 | 说明 |
|--------|------|------|
| 1ml | **0.35** | 极少，总精子数大概率不达标 |
| 3ml | **0.7** | 正常偏低，刚跨过达标线 |
| 5ml | **1.0** | 基准量，正常射精量 |
| 10ml | **1.35** | 罕见大量，饱和效应开始 |
| 20ml | **1.6** | 现实中不存在，强弩之末 |
| 50ml | **3.0** | 超自然级别的分水岭 |
| > 50ml | **3.0 × (量/50)^1.2** | 幂函数外推，越往后越猛 |

档位之间连续插值（如 25ml 自动计算为 20ml 和 50ml 之间的线性插值结果）。50ml 以下保持现实向饱和曲线，50ml 以上作为游戏化夸张放开。

### 5.3 随机判定

触发条件（三项同时满足）：

1. `宫内精液.总量 > 0`
2. `生理周期.当前阶段 = "排卵期"`
3. `怀孕状态.状态 = "未孕"`

判定方式为**阈值比较**：

```
randomValue = Math.random()           // 生成 [0, 1) 均匀分布的伪随机浮点数
概率        = 日期系数 × 年龄系数 × 精液系数

if (randomValue < 概率):
    → 受精成功
else:
    → 本次未受精
```

`Math.random()` 输出在 [0, 1) 区间内均匀分布。例如概率为 0.09，则 randomValue 落在 [0, 0.09) 区间的概率恰好为 9%。

#### 判定时机说明

每 tick（每游戏日）对每个满足条件的女性角色做一次独立判定。排卵窗口横跨 3 天（周期第 14-16 天），即每个排卵期最多 3 次独立判定。三次独立判定叠加后，每周期累积概率约 24%，吻合真实数据。

#### 计算示例

**周汝，21岁，排卵第 14 天（日期系数 0.12），体内 4ml 精液：**

```
4ml 在 3ml(0.7) 和 5ml(1.0) 之间线性插值：
精液系数 = 0.7 + (4-3)/(5-3) × (1.0-0.7) = 0.85

概率 = 0.12 × 1.0 × 0.85
     = 10.2%

Math.random() < 0.102 → 10.2% 概率命中
```

周期总概率（三天累积）：1 - (1 - 0.102) × (1 - 0.0765*) × (1 - 0.0425*) ≈ **20.5%**
*第 15 天 0.09 × 1.0 × 0.85 = 0.0765, 第 16 天 0.05 × 1.0 × 0.85 = 0.0425

**张云，43岁，排卵第 15 天（日期系数 0.09），体内 2ml 精液：**

```
2ml 在 1ml(0.35) 和 3ml(0.7) 之间线性插值：
精液系数 = 0.35 + (2-1)/(3-1) × (0.7-0.35) = 0.525

概率 = 0.09 × 0.1 × 0.525
     = 0.47%

Math.random() < 0.0047 → 0.47% 概率命中
```

周期总概率约 1.1%，几乎不可能自然受孕。

#### 成功时

```
怀孕状态.状态    = "受精"
怀孕状态.受孕日期 = 当前世界日期（去掉星期和时间，只保留 "2026年04月06日" 格式）
怀孕状态.父方    = 宫内精液.来源
```

### 5.4 孕周计算

不存储孕周，每次 tick 实时推算：

```
孕周 = floor(daysBetween(受孕日期, 当前世界日期) / 7)
```

以受孕日期为孕 0 周起点。例如 4月6日受孕，4月20日时孕周 = 2。

### 5.5 阶段推进

| 孕周范围 | 状态 | 说明 |
|----------|------|------|
| 0 ~ 1 | **受精** | 受精卵着床期，角色自身通常不知 |
| 2 ~ 13 | **早孕** | 可能出现早孕反应（恶心、嗜睡），第 12 周后进入中孕 |
| 14 ~ 27 | **中孕** | 腹部隆起，开始显怀 |
| 28 ~ 37 | **晚孕** | 明显大腹，行动不便 |
| ≥ 38 | 触发分娩 | → 状态切为 **产褥期** |

### 5.6 分娩判定

当 `孕周 >= 38` 且状态仍为 `晚孕` 时：

```
怀孕状态.状态 = "产褥期"
// 受孕日期保留不动，产后天数用它 + 266天推导
```

分娩触发后，主 AI 应在叙事中向 `生育记录` 追加一条记录：

```
生育记录.push({ 生产日期: 当前世界日期, 父方: 怀孕状态.父方, 孩子: /* AI 写入新生儿姓名 */ })
```

日期格式为 `"YYYY年MM月DD日"`，与世界日期对齐。

### 5.7 产褥期

产后天数的计算：

```
产后天数 = daysBetween(受孕日期 + 266天, 当前世界日期)
```

当 `产后天数 >= 42`（6 周）：

```
怀孕状态.状态    = "未孕"
怀孕状态.受孕日期 = null
怀孕状态.父方    = null
生理周期.上次经期日 = 当前世界日期   // 重置周期，从今天重新开始计数
生理周期.当前阶段   = "经期"         // 产后首次经期
```

## 六、每条 tick 的执行流程

每游戏日一次 tick，对每个女性角色执行。若跨越多日，逐日迭代补全中间状态。

```
tickFemalePhysiology(character, worldTime, age):

  // ──── 1. 生理周期（仅在未孕时运行）───
  if 怀孕状态.状态 == "未孕":
      daysSince = daysBetween(上次经期日, worldTime.date)
      if daysSince >= 周期天数:
          上次经期日 += 周期天数      // 推进到下一个周期
          daysSince = daysBetween(上次经期日, worldTime.date)
      
      currentDay = (daysSince % 周期天数) + 1
      当前阶段 = 判定阶段(currentDay, 经期长度)
  // 怀孕期间跳过：排卵和月经停止，周期天数和上次经期日均不动

  // ──── 2. 宫内精液衰减（逐日迭代）───
  if 总量 > 0 and 注入时间:
      daysTotal = daysBetween(注入时间.date, worldTime.date)
      for d = 1 to daysTotal:
          // 逐日推进，根据当天阶段选择衰减率
          当天日期 = 注入时间.date + d 天
          当天阶段 = 计算该日期所处的周期阶段(character, 当天日期)
          衰减率 = (当天阶段 == "排卵期") ? 0.97 : 0.85
          总量 = 总量 × 衰减率^24
          if 总量 < 0.01:
              总量 = 0; 来源 = null; 注入时间 = null
              break

  // ──── 3. 受精判定 ────
  if 状态 == "未孕" and 总量 > 0 and 当前阶段 == "排卵期":
      日期系数 = 查表(currentDay)   // 第14天0.12, 第15天0.09, 第16天0.05
      年龄系数 = 查表(age)
      精液系数 = clamp(总量 / 3, 0.3, 1.3)
      概率 = 日期系数 × 年龄系数 × 精液系数
      if random() < 概率:
          状态 = "受精"
          受孕日期 = worldTime.date
          父方 = 来源

  // ──── 4. 怀孕阶段推进 ────
  else if 状态 ∈ ["受精", "早孕", "中孕", "晚孕"]:
      孕周 = floor(daysBetween(受孕日期, worldTime.date) / 7)
      if 孕周 >= 38 and 状态 == "晚孕":
          状态 = "产褥期"
      else if 孕周 >= 28 and 状态 == "中孕":
          状态 = "晚孕"
      else if 孕周 >= 14 and 状态 == "早孕":
          状态 = "中孕"
      else if 孕周 >= 2 and 状态 == "受精":
          状态 = "早孕"

  // ──── 5. 产褥期恢复 ────
  else if 状态 == "产褥期":
      产后天数 = daysBetween(受孕日期 + 266天, worldTime.date)
      if 产后天数 >= 42:
          状态 = "未孕"
          受孕日期 = null
          父方 = null
          上次经期日 = worldTime.date    // 周期从今天重启
          当前阶段 = "经期"
```

### 关键设计说明

- **逐日迭代而非单次公式**：精液衰减需要根据每天所处的生理阶段切换衰减率（排卵期 0.97^24，非排卵期 0.85^24）；孕周推进也需要每天都检查阶段边界。当世界跳过数日时，逐日迭代确保中间状态不丢。
- **周期冻结**：只要 `状态 != "未孕"`，周期计算全部跳过。`当前阶段` 维持怀孕前最后的值不变，直到产后重置。
- **产后重置**：产褥期结束 → 未孕时，`上次经期日` 设为当前日期，`当前阶段` 设为 `"经期"`，生理周期从今天重新开始。

## 七、AI 注入

### 7.1 character-filter 扩展

在 `character-filter.ts` 格式化人物信息时，根据目标人物的 `子宫` 变量追加可读文本。暴露程度由亲密度控制：

| 信息 | 陌生人 | 熟人 | 亲密 |
|------|--------|------|------|
| 中孕/晚孕的体态 | ✓ | ✓ | ✓ |
| 经期不适（情绪/状态） | — | ✓ | ✓ |
| 早孕反应 | — | — | ✓ |
| 排卵期/安全期 | — | — | ✓ |
| 宫内精液 | — | — | ✓ |

### 7.2 注入格式示例

```
// 陌生人视角 — 只看到显怀
"顾昀看起来腹部微微隆起，行动略显迟缓。"

// 亲密关系 — 全部可见
"顾昀正处于排卵期，体内残留着周安的3.2ml精液。已怀孕14周（中孕），腹部明显隆起。"
```

### 7.3 叙事中的体现

主 AI 拿到这些信息后，自然会反映到叙事中：
- 经期：NPC 可能情绪烦躁、需要休息
- 早孕：NPC 自己可能尚未察觉
- 中孕/晚孕：NPC 行为受限，外观变化明显
- 产褥期：NPC 需要照料新生儿

### 7.4 AI 可写变量

除了代码自动计算的变量外，以下变量由主 AI 在叙事中通过 `<vars>` 写入：

| 变量 | 触发场景 | 说明 |
