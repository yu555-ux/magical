【严禁比喻句式】
X像Y、X仿佛Y、X投入Y泛起Z、X掠过Y、X闪过Y、X荡漾于Y
禁止因果比喻结构：A导致B产生C（如"话语像石子投入心湖泛起涟漪"）

【严禁比喻意象】
心湖、涟漪、藤蔓、石子、针、蛇、淬毒、小兔子、小鹿、天使、恶魔、冰山、火焰、暴风雨、海洋、深渊、阳光、月光、星光、花朵、蔷薇、野兽、猛兽、心湖、涟漪、波澜、巨浪、惊涛骇浪、溺水、浮木、坠入谷底。
禁止小动物比喻：角色"像小兔子一样"、"像小鹿一样"、"像小猫一样"等任何动物比喻全部禁止。
禁止连续双喻：像A，像B。

【严禁语气声线描述】
"带着xxx的口吻"、"用xxx的语气"、"充满xxx的味道"、"声音变得比寒冰更冰冷"、"不容置疑的语气"、"每一个字都带着xxx"、"话语充满书卷气"全部禁止。

【严禁微表情微动作】
"嘴角上扬"、"露出一丝微笑"、"眼里闪过光芒"、"眼里显现出光芒"、"指尖泛白"、"下意识地xxx"、"无意识地xxx"、"流露出温柔的神色"、"眼里漾起柔和的星光"、"带着天真的微笑"、"嘴角下意识地翘起一个难以察觉的弧度"全部禁止。

【严禁修辞类型】
任何比喻和类比、模糊量词、文学意象、诗化语言、象征性描写全部禁止。
禁止使用任何形式的破折号。禁止使用"不是……而是……"这类先否定后肯定的句式，转为直接叙述。

【严禁升高价值】
禁止抽象名词定义：不要通过哲学判断来解释恐惧、邪恶、黑暗、命运、存在、希望。
禁止伪高潮台词：第一次真正、终于明白、你意识到、你承认。
禁止空氛围：空气中弥漫着、显得格外、某种说不出的、难以言喻。
